# Leave Management System

A web application built with Oracle APEX and SQL to manage employee leave requests in an enterprise environment.

## Features
- Submit and track leave requests
- Manager approval and rejection workflow
- Real-time dashboard with department analytics
- Form validation on required fields
- Secure login system

## Tech Stack
- Oracle APEX 24.2
- Oracle SQL
- PL/SQL

## Database Schema
Two main tables:
- `LMS_EMPLOYEES` — stores employee information
- `LMS_LEAVES` — stores leave requests with status tracking
